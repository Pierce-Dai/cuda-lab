## 怎么利用 basic-cuda-tutorial

1. 先读 `.zh.md` 中文文档。
2. 再跑 `.cu` 示例。
3. 复制核心思想到你自己的代码中，但不要照抄。
4. 每个例子后写一句总结：

```text
这个例子教会了我 CUDA 的哪个机制？
```
